## 摘要
多模态大语言模型越来越多地被部署为长期运行的智能体，其记忆必须超越简单的回忆：它必须跟踪不断演变的世界，修正过时的信息，并在决策时刻提供正确的证据。现有的基准测试评估的是静态对话中的回忆能力，将记忆压缩为单一的任务结束准确性，并将视觉观察简化为文字说明，导致我们无法将失败定位到写入、维护、检索或使用等环节。可自主管理记忆的智能体框架的兴起进一步加剧了这一差距，因为我们没有原则性的方法来比较手工设计的流程与自我管理的替代方案。为弥补这些差距，我们将多模态智能体记忆形式化为具有可观察四阶段生命周期的行动-世界交互循环，并在WorldMemArena中实例化：400个多会话多模态任务，涵盖终身演化（演化的个人和任务状态）和智能体执行（来自真实观察、行动和反馈的记忆），并标注了黄金记忆点、更新、干扰项和用于阶段级诊断的证据链。这首次实现了长上下文、手动设计（RAG和外部记忆系统）和基于框架的记忆智能体之间的直接比较。结果表明：（1）更好的记忆写入和存储并不能保证更好的性能；（2）多模态记忆仍难以充分利用视觉证据；（3）系统在不同领域间不稳定，并在现实的智能体轨迹上性能下降；（4）框架记忆更灵活但成本高且可靠性较低。

## Abstract
Multimodal large language models are increasingly deployed as long-horizon agents, where memory must do more than recall: it must track an evolving world, revise what has gone stale, and surface the right evidence at decision time. Existing benchmarks measure recall over static dialogue, collapse memory into a single end-of-task accuracy, and reduce visual observations to captions, leaving us unable to localize failures to writing, maintenance, retrieval, or use. The rise of agent harnesses that author their own memory sharpens this gap, since we have no principled way to compare hand-designed pipelines with self-managing alternatives. To close these gaps, we formulate multimodal agent memory as an Action-World Interaction Loop with an observable four-stage lifecycle, and instantiate it in WorldMemArena: 400 multi-session multimodal tasks spanning Lifelong Evolution (evolving personal and task states) and Agentic Execution (memory from real observations, actions, and feedback), annotated with gold memory points, updates, distractors, and evidence chains for stage-level diagnosis. This enables the first head-to-head comparison of long-context, manually designed (RAG and external memory systems), and harness-based memory agents. Results show that: (1) better memory writing and storage do not guarantee better performance; (2) multimodal memory still struggles to fully use visual evidence; (3) systems are unstable across domains and degrade on realistic agentic trajectories; and (4) harness memory is more flexible but remains costly and less reliable.

## 2. 方法论：核心思想、关键技术细节
### 核心思想
- 将记忆视为**行动-世界交互循环**的一部分。智能体观察部分可见世界、采取行动、接收反馈，并通过记忆保留有用证据以指导未来行动。记忆具有可观察的生命周期：写入、维护、检索、使用。

### 四阶段生命周期定义
1. **Observe to Write**：评估系统能否从当前会话中识别未来有用的证据并选择性写入，而非存储全部轨迹。
2. **Update and Consolidate**：评估系统如何将新信息整合到现有记忆中，支持修订、合并和删减过时内容。
3. **Retrieve for Decision**：评估系统是否能在查询或决策时检索到正确的证据（超越语义相似度，关注决策相关性）。
4. **Use and Act**：评估检索到的记忆是否被忠实用于最终响应/行动，避免忽略证据、依赖过时信息或无法转化经验。

### 数据集构建
- **两个互补场景**：
  - **Lifelong Evolution**（终身演化）：个人和项目状态跨会话演变，要求持续跟踪、更新和重用长期记忆。涵盖专业领域（学术、软件、健康等）和整体人生轨迹。
  - **Agentic Execution**（智能体执行）：来源于真实或现实的智能体轨迹（导航、机器人操作、桌面GUI等），系统必须从观察、行动和反馈中提取可重用证据。
- **数据规模**：461个多会话任务，平均每任务18.4个会话，约9.1K token，含24,258个QA对、15,595张图像/截图。
- **细粒度标注**：每个会话标注黄金记忆点、状态更新点、干扰项，每个QA配对标注所需证据链。支持按阶段诊断。

### 评估协议
- 每个阶段使用对应指标：
  - **写阶段**：Memory Recall、Memory Correctness/Hallucination/Irrelevance
  - **维护阶段**：Update Handling（更新处理）、Interference Rejection（干扰拒绝）

## 6. 主要结论与发现
1. **更好存储 ≠ 更好性能**：高记忆召回率不一定带来高QA正确率（如Qwen3-VL-Embedding和M2A存储好但答案质量差）。
2. **多模态记忆瓶颈严重**：视觉证据利用不足，尤其在需要视觉推理、跨模态整合的任务上表现差。多数系统将图像压缩为文本，丢失空间、时间、程序细节。
3. **系统稳定性差**：在智能体执行场景中表现显著低于终身演化场景；长对话任务比智能体任务更容易。领域分化明显，导航、GUI等认知密集场景挑战更大。
4. **框架记忆灵活但代价高**：Codex、OpenClaw等性能优于部分手工设计系统，但计算成本高、可靠性较低、框架依赖强。
5. **记忆维护以“追加”为主，缺乏修订和删除**：大部分系统倾向于累积记忆而非保持时间一致性，更新处理能力差。
6. **检索仍是性能瓶颈**：即使存储正确，检索阶段的召回和排序不足导致下游失败。
7. **经验性证据容易被忽略**：工具反馈、失败动作、视觉细节等易于丢失，而显式文本事实更容易保留。
