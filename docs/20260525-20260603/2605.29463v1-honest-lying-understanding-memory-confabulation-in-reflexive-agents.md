## 摘要
反射型代理依赖自我生成的反思作为记忆，隐式假设代理能够准确诊断自己的失败。我们表明这一假设可能系统性地失败：在ALFWorld和HumanEval中，代理存储了对任务的自信但错误的解释，并在多次试验中继续据此行动，尽管环境每次都会重置为正确的任务。我们将这种失败模式称为记忆虚构，并引入反思重复率（RRR），这是一种基于日志的度量，用于检测对错误反思内容的重复依赖。使用RRR，我们在ALFWorld中识别出16个冻结环境，其中121条反思中0条提到正确的目标对象，以及在HumanEval中发现了4个类似案例。我们的缓解方法是用程序化提取轨迹级失败信号替代开放式自我诊断，将正确对象提及率从0%提高到86%，RRR从0.64降低到0.10，并解决了ALFWorld中16个冻结环境中的3个，表明反思记忆可能强化而非纠正错误信念。

## Abstract
Reflexion-style agents rely on self-generated reflections as memory, implicitly assuming that agents can accurately diagnose their own failures.We show that this assumption can fail systematically: across ALFWorld and HumanEval, agents store confident but incorrect interpretations of the task and continue acting on them across trials,even though the environment resets to the correct task each time. We call this failure mode memory confabulation and introduce the Reflection Repetition Rate (RRR), a log-based metric that detects repeated reliance on incorrect reflective content.Using RRR, we identify 16 frozen environments in ALFWorld, where 0 of 121 reflections mention the correct target object, and 4 analogous cases in HumanEval. Our mitigation replaces open-ended self-diagnosis with programmatic extraction of trajectory-level failure signals, increasing correct object mention from 0% to 86%, reducing RRR from 0.64 to 0.10, and solving 3 of 16 frozen ALFWorld environments, suggesting that reflective memory can reinforce false beliefs rather than correct them.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：反射型智能体（如Reflexion）在多次试验中依赖自我生成的反思作为记忆，其核心假设是智能体能够准确诊断自身失败原因。但这一假设可能系统性地失败：智能体可能存储自信但错误的任务解释，并在后续试验中持续依赖这些错误记忆，即使环境每次重置为正确任务。
- **背景**：Reflexion是一种代表性的反思机制：失败后，智能体生成自然语言反思，并在后续尝试中检索。当反思正确时，可将失败行动转化为可复用经验。但作者发现，反思可能产生“记忆虚构”（memory confabulation）——持久性、自我增强的错误信念被写入反思记忆并据此行动，尽管存在矛盾的任务证据。
- **问题定义**：记忆虚构与幻觉（hallucination）不同：幻觉是单次生成错误，而记忆虚构是多试验的失败模式，错误内容被存储、检索、行动，并被后续反思强化。这导致反思记忆可能强化而非纠正错误信念，对智能体设计有重要启示。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：定义并量化记忆虚构，提出反射重复率（RRR）作为检测工具，并通过程序化提取轨迹级失败信号进行缓解。

    RRR = \frac{|\{r_i : i \geq 1, \exists j < i, sim(r_i, r_j) \geq 0.85\}|}{|M| - 1}

## 6. 主要结论与发现

- 反思型智能体系统性地出现记忆虚构：ALFWorld中16个冻结环境，121条反思中0条提及正确目标对象。

- 因果证据：2个环境（Memory-harmful）在无记忆时1次试验解决，而有记忆需要7-8次试验，证明反思记忆可主动有害。

- 更强的模型（gpt-4o-mini）消除任务标识虚构（提及率100%），但仅解决2/16环境，且伴随新虚构类型（格式虚构、动作空间虚构），说明结构性漏洞独立于模型能力。
