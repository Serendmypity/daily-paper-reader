## 摘要
长期记忆对于LLM智能体在扩展交互中连贯推理、个性化响应和复用过去经验至关重要。然而，现有的记忆增强方法通常将记忆视为固定资源：文本空间方法将检索到的记忆拼接到上下文窗口中，导致大量token开销和对噪声证据的敏感性，而潜在空间方法减少了文本成本，但仍依赖于刚性检索或固定容量的记忆接口。这在查询相关的记忆效用和固定记忆分配之间造成了不匹配。我们提出ElasticMem，一种记忆增强的LLM框架，学习将记忆用作弹性潜在资源。ElasticMem构建了一个离线潜在记忆库，包含检索键和内容缓存，从推理器的隐藏状态中自适应地检索记忆，通过学习的策略为每个检索到的记忆分配可变潜在预算，并将选中的潜在状态作为软记忆token注入用于生成。完整的记忆使用过程通过组相对策略优化与下游任务奖励进行优化。我们在MemorySuite上评估ElasticMem，涵盖记忆密集型问答和具身智能体控制。在Qwen2.5-3B-Instruct和Qwen2.5-7B-Instruct骨干网络上，ElasticMem相比于最强基线，在加权平均QA准确率上分别提升了26.2%和24.6%，在ALFWorld成功率上分别提升了66.3%和27.2%，同时实现了最低的ALFWorld token成本。消融和定性分析进一步表明，自适应检索和弹性预算分配帮助ElasticMem优先处理超越刚性余弦相似度的有用证据和可迁移计划。我们的ElasticMem代码将在https://github.com/ulab-uiuc/ElasticMem发布。

## Abstract
Long-term memory is essential for LLM agents to reason coherently across extended interactions, personalize responses, and reuse past experience. However, existing memory-augmented methods typically treat memory as a fixed resource: text-space approaches concatenate retrieved memories into the context window, causing substantial token overhead and sensitivity to noisy evidence, while latent-space approaches reduce textual cost but still rely on rigid retrieval or fixed-capacity memory interfaces. This creates a mismatch between query-dependent memory utility and fixed memory allocation. We propose ElasticMem, a memory-augmented LLM framework that learns to use memory as an elastic latent resource. ElasticMem builds an offline latent memory bank with retrieval keys and content caches, retrieves memories adaptively from the reasoner's hidden state, assigns each retrieved memory a variable latent budget through a learned policy, and injects selected latent states as soft memory tokens for generation. The full memory-use process is optimized with downstream task rewards through group-relative policy optimization. We evaluate ElasticMem on MemorySuite, covering memory-intensive QA and embodied agent control. Across Qwen2.5-3B-Instruct and Qwen2.5-7B-Instruct backbones, ElasticMem improves weighted average QA accuracy by 26.2% and 24.6%, and improves ALFWorld success rate by 66.3% and 27.2%, respectively, over the strongest baselines, while achieving the lowest ALFWorld token cost. Ablations and qualitative analyses further show that adaptive retrieval and elastic budget allocation help ElasticMem prioritize useful evidence and transferable plans beyond rigid cosine similarity. Our code for ElasticMem will be released at https://github.com/ulab-uiuc/ElasticMem.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：现有LLM智能体的长期记忆方法将记忆视为固定资源，导致两种主要缺陷：一是文本空间方法将检索到的记忆直接拼接到上下文，造成大量token开销，且易受噪声证据干扰；二是潜在空间方法虽然减少了文本开销，但依赖刚性检索（如固定余弦相似度）或固定容量的记忆接口，无法根据查询和任务实际效用动态分配记忆表示能力。
- **根本矛盾**：记忆的有用性是查询依赖和任务依赖的，但现有系统的检索和容量分配却是固定的，导致高语义相似但无用的记忆占用资源，而低相似但包含关键证据的记忆被忽视。
- **研究目标**：提出一种机制，使LLM智能体能够学习自适应检索和弹性分配记忆容量，让有用记忆获得更多表示预算，无用的被压缩或抑制。

## 2. 方法论：核心思想、关键技术与算法流程

### 2.1 核心思想
ElasticMem将记忆使用视为一个可学习的资源分配问题，包括四个阶段：离线潜在记忆库构建、基于推理器状态的查询自适应检索、弹性潜在预算分配、潜在记忆注入，并通过组相对策略优化（GRPO）联合优化整个记忆使用过程。

### 2.2 关键技术细节

1. **离线潜在记忆库构建**：
   - 将记忆语料库划分为N个块，每个块由冻结的基础LLM编码器一次编码。
   - 提取两个表示：最后隐藏状态作为检索键 \(k_i\)；最后\(N_c\)个隐藏状态作为内容缓存\(C_i\)。
   - 形成只读记忆库\(\mathcal{B} = \{(m_i, k_i, C_i)\}_{i=1}^N\)，训练期间不更新。

2. **查询自适应检索**：
   - 推理器首先采样一个检索控制token \(a \sim p_\theta(\cdot|q)\)。
   - 将查询和该token输入LoRA适配的推理器，取最后隐藏状态作为查询表示\(h_q\)。
   - 通过余弦相似度\(s_i = \cos(h_q, k_i)\)对记忆库排序，选择top-Z块作为候选集。

3. **弹性潜在预算分配**：
   - 对每个检索到的块\(m_{I_j}\)，分配一个离散预算\(b_j \in \{0, 1, \dots, B_{\max}\}\)，\(b_j=0\)表示完全抑制。
   - 预算策略网络\(\pi_\phi\)是一个轻量级Transformer编码器，输入为查询状态、检索键、元素积、检索分数和排名嵌入，输出每个块上预算的logits，通过分类分布采样。
   - 该策略不模仿余弦分数，仅通过下游奖励优化，使其能对低相似但有用的块分配大预算。

4. **潜在记忆注入**：
   - 对每个块，根据预算\(b_j\)从内容缓存中选取最后\(b_j\)个状态，通过可学习投影器\(P_\psi\)映射为软记忆token \(Z_j\)。
   - 最终输入序列为：\(X = [E(q); E(a); Z_1; \dots; Z_Z; E(u)]\)，其中u是任务指令。

5. **基于奖励的优化**：
   - 使用GRPO联合优化LoRA推理器\(\theta\)、预算策略\(\phi\)和投影器\(\psi\)。
   - 每个查询采样G个轨迹\(\tau_g = (a_g, I_g, b_g, y_g)\)，计算任务奖励\(r_g\)，归一化为优势，最小化裁剪后的GRPO损失。
   - 轨迹似然分解为检索控制token概率、每个块预算概率和生成概率的乘积。

## 6. 主要结论与发现

1. ElasticMem在记忆密集型QA和具身决策任务上均显著优于文本空间和固定容量潜在空间方法。

3. 弹性预算分配（通过Transformer策略学习）比均匀分配或简单MLP更好，能区分有用和冗余记忆。
