## 摘要
智能体LLM必须持续判断新提取的事实是否应被添加、与现有记忆合并或忽略，然而先前的工作更多地聚焦于检索与存储，而非原则性的写侧控制。我们将记忆演化建模为新颖性检测问题，并提出SAGE（球面自适应门控用于记忆演化），该方法利用基于冯·米塞斯-费歇尔的密度估计器对记忆嵌入上的候选事实进行评分，并通过跟踪记忆存储几何形状的自适应阈值对其进行路由。SAGE将明确的新颖事实判定为“添加”，明确的冗余事实判定为“无操作”，仅将不确定的案例发送至LLM合并步骤，从而减少了昂贵的写时推理。在LoCoMo上，SAGE在所有七个开放权重骨干对比中相对于Mem0取得了最佳的平均token-F1，而在GPT-4o-mini上，它实现了添加阶段API成本降低3.4倍，添加阶段延迟降低2.5倍，仅有微小的平均评判分数差距。作为A-Mem的即插即用二值门控，SAGE在五个模型上跳过了大约16-18%的LLM调用，且对开放权重骨干的质量影响极小。这些结果表明，新颖性感知的写控制是提升长期智能体记忆中记忆质量与系统效率的实用杠杆。

## Abstract
Agentic LLMs must continuously decide whether newly extracted facts should be added, merged with existing memories, or ignored, yet prior work has focused more on retrieval and storage than on principled write-side control. We frame memory evolution as a novelty-detection problem and propose SAGE, a Spherical Adaptive Gate for memory Evolution that scores candidate facts with a von Mises-Fisher-based density estimator over memory embeddings and routes them with an adaptive threshold that tracks memory-store geometry. SAGE resolves clearly novel facts as ADD, clearly redundant facts as NOOP, and sends only uncertain cases to an LLM merge step, reducing expensive write-time reasoning. On LoCoMo, SAGE achieves the best average token-F1 against Mem0 on all seven open-weight backbone comparisons, while on GPT-4o-mini it reduces add-phase API cost by 3.4$\times$ and add-phase latency by 2.5$\times$ with only a small average judge-score gap. As a drop-in binary gate for A-Mem, SAGE skips roughly 16-18% of LLM calls across five models with minimal quality change on open-weight backbones. These results suggest that novelty-aware write control is a practical lever for improving both memory quality and system efficiency in long-term agentic memory.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：智能体LLM（Agentic LLM）需要长期维护一个可演化的记忆存储，但现有系统侧重于“如何检索”和“如何存储”，而忽略了“何时写、如何写”这一关键决策。写入决策一旦出错（重复、错误合并、过早删除）将严重损害下游检索质量。
- **背景**：现有系统如Mem0、A-Mem完全依赖LLM对每个新事实进行写端路由（ADD/UPDATE/DELETE/NOOP），成本高昂且缺乏原则性控制。作者将记忆演化重新定义为“新颖性检测”问题，提出一种轻量级、几何对齐的写端控制方法。

## 2. 论文提出的方法论

- **核心思想**：通过基于von Mises-Fisher（vMF）分布的核密度估计器，计算新事实相对于当前记忆存储的新颖性分数，再利用自适应阈值进行三路路由：明确新颖→ADD（无需LLM）、明确冗余→NOOP（无需LLM）、不确定→LLM合并（仅此需要LLM调用）。
- **关键技术细节**：
  - 记忆嵌入经ℓ2归一化至单位超球面S^(d-1)上。
  - 使用vMF核函数K_κ(c, m_i) = exp(κ m_i^T c)，计算平均支持度：Ŝ(c|M) = (1/N) Σ_i K_κ(c, m_i)。
  - 新颖性分数ν(c) = (1 - s_vMF(c|M))/2，其中s_vMF = (1/κ) log Ŝ(c|M)，ν越大表示越新颖。
  - 浓度参数κ由均值合成长度R估计：κ ≈ R(d - R²)/(1 - R²)，使门控自适应于记忆分布的稀疏/密集状态。
  - 密度代理ρ_t = N_t / V_t（V_t为PCA投影后各维范围之积），用于动态调整阈值：τ*_t = τ_min + τ_0 e^{-λ ρ_t}，再经EMA平滑得τ_t。
  - 路由规则：ν(c) ≥ τ_t + δ → ADD；τ_t ≤ ν(c) < τ_t + δ → LLM合并；ν(c) < τ_t → NOOP。
  - 扩展：作为即插即用二值门控，设定固定阈值τ_noop，当s_vMF(c|M) > τ_noop时直接NOOP，否则交予下游系统。

## 6. 论文的主要结论与发现

- SAGE在7/7开放权重骨干上平均token-F1优于Mem0和Mem0_g，并且BLEU-1在5/7骨干上最优。
- 相比Mem0，SAGE在GPT-4o-mini上降低添加阶段API成本3.4倍、延迟2.5倍、总token减少2.6倍，仅牺牲1.3平均J分数。
- 作为A-Mem的NOOP门控，跳过16–18%的写端LLM调用，对开放权重骨干的F1和J变化小于0.5%。
- 自适应阈值相比固定阈值更鲁棒：固定阈值在Qwen2.5-3B上高阈值时质量急剧下降，而自适应自动追踪记忆密度。

## 7. 优点

- **方法创新**：首次将记忆演化定义为新颖性检测问题，提出基于vMF的轻量级门控，填补了写端原则性控制的空白。
- **高效性**：通过闭环决策免除大多数LLM调用，实现质量与效率的双赢而非权衡。
- **理论合理性**：评分函数有界（[-1,1]），自适应阈值基于记忆几何动态调整，避免手动调参。
- **实验设计全面**：同时评估质量（F1、BLEU、Judge）和效率（API cost、延迟、token数），并单独隔离NOOP的影响。
- **即插即用**：作为二值门控可无入侵地集成到现有系统（A-Mem）中，兼容性好。

## 8. 不足与局限

- **场景覆盖有限**：仅LoCoMo基准（英语多会话对话），未测试多语言、任务导向、工具使用或更长时间范围（如LongMemEval）。
- **动作不完整**：SAGE仅执行ADD、UPDATE、NOOP，不包括DELETE决策，缺乏记忆压缩/遗忘机制。
- **依赖嵌入质量**：vMF评分继承嵌入模型的偏差，语义不同但向量相近的事实可能被错误抑制，反之同义但向量分散的事实可能绕过冗余过滤。
- **参数敏感性**：虽然自适应阈值通用，但δ（不确定带宽度）需人工设定，影响LLM调用比例。
- **GPT-4o-mini上的J分数有1.3点下降**，说明在强大骨干上门控可能损失部分回忆质量，尤其是时间推理。
- **未与其他RL-based方法（Memory-R1、Mem-α）对比**，仅与LLM路由法比较。
