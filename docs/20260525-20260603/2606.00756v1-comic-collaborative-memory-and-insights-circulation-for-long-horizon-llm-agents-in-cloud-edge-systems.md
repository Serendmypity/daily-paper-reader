## 摘要
在边缘服务器上部署轻量级大语言模型（LLM）智能体可以降低延迟并将智能服务靠近用户，但资源受限的边缘模型在处理需要持久记忆、子目标跟踪和反思的长时程任务时往往表现不佳。部署后对边缘模型进行微调成本高昂且难以在异构节点上扩展，而纯本地记忆则导致智能体经验孤立且提示上下文不断增长。我们提出 \textsc{CoMIC}，一种无需参数更新的云-边缘协作记忆与洞察循环框架。\textsc{CoMIC} 采用“集中反思、分散执行”的设计：边缘智能体使用面向子目标的分层记忆和对相关历史的选择性重新扩展来本地执行，而云端LLM评论者异步评估已完成轨迹、过滤可复用经验，并聚合以语义子目标标识符为键的跨智能体指导。在涵盖符号规划和文本交互的五项长时程智能体任务中，\textsc{CoMIC} 提升了弱边缘智能体的进展率和动作基础性，并在不更新模型参数的情况下获得了依赖于任务的成功率增益。

## Abstract
Deploying lightweight Large Language Model (LLM) agents on edge servers can reduce latency and move agentic services closer to users, but resource-constrained edge models often struggle with long-horizon tasks that require persistent memory, subgoal tracking, and reflection. Fine-tuning edge models after deployment is costly and difficult to scale across heterogeneous nodes, while purely local memory leaves agents with isolated experience and growing prompt context. We propose \textsc{CoMIC}, a parameter-update-free cloud-edge framework for Collaborative Memory and Insights Circulation. \textsc{CoMIC} follows a \textit{Centralized Reflection, Decentralized Execution} design: edge agents execute locally using subgoal-oriented hierarchical memory and selective re-expansion of relevant histories, while a cloud-side LLM critic asynchronously evaluates completed trajectories, filters reusable experience, and aggregates cross-agent guidance keyed by semantic subgoal identifiers. Across five long-horizon agent tasks spanning symbolic planning and text interaction, \textsc{CoMIC} improves progress rate and action grounding for weak edge agents and yields task-dependent success-rate gains without updating model parameters.

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

### 2.1 核心思想：集中反思、分散执行（Centralized Reflection, Decentralized Execution）

- **边缘层**：每个边缘智能体 \( e_i \) 将全局任务 \( g \) 分解为一系列子目标（subgoal）片段 \( \hat{\tau}_{it} \)，维护分层本地记忆（当前子目标保留详细动作-观察对，已完成子目标压缩为摘要），并通过选择性重新扩展（selective re-expansion）重构历史上下文。
- **云端层**：一个 LLM 评论者（Cloud Critic）异步接收边缘上传的完整轨迹，进行独立评估、过滤高质量经验，并聚合跨智能体经验为全局指导（Global Guidance），以语义子目标标识符（semantic subgoal identifier）为键进行索引和分派。

### 2.2 关键技术细节

1. **边缘框架**：
   - 子目标驱动执行：每个子目标片段记录为 \( \hat{\tau}_{it} = (g, g_{it}, o_{it}, a_{it}, r_{it}) \)。
   - 分层记忆与摘要器：当前子目标保留原始细节；已完成子目标压缩为摘要；通过索引集 \( I \) 选择性重新扩展现需详细信息。
   - 历史上下文重建：\( H_{it}(I) = \{ \text{Summary}(\hat{\tau}_{it})_{t \notin I} \} \cup \{ \hat{\tau}_{it} \}_{t \in I} \)。
2. **云端 LLM 评论者**：
   - 单轨迹规范化与评估：对上传轨迹进行序列化（包括规范化的特征集合 \( \tilde{m}_{it} \)），利用缓存避免重复调用。
   - 经验蒸馏：评估输出包含摘要、洞见、建议和自报告置信度 \( s_{\text{self}} \)。定义准入分数 \( s_{\text{adm}}(x_{it}) = \text{clip}_{[0,1]}( s_{\text{self}} - \lambda_{\text{ctx}} I_{\text{retry}} - \lambda_{\text{short}} I_{\text{short}} ) \)，仅当分数 \( \ge \gamma_{\text{kb}} \) 时经验进入知识库。
   - 记忆组织：短期缓存（上传轨迹与中间评估）+ 长期知识库（经验记忆 \( M_{\text{exp}} \) 和全局指导 \( M_{\text{global}} \)）。
3. **云-边缘协作机制**：
   - 跨边缘聚合：按子目标标识符 \( u \) 分组经验，聚合为全局指导 \( \mathcal{G}(u) = f_{\text{agg}}(G(u)) \)。
   - 协作上下文组装：边缘在启动新子目标时，通过组装函数 \( \mathcal{A} \) 将全局指导嵌入提示中：\( P_{it+1} = \mathcal{A}(g, g_{it+1}, o_{it+1}, H_{it+1}(I_{t+1}), \mathcal{G}(u_{t+1}) ) \)。
- **算法流程**（算法1）：
  1. 云端路径：序列化轨迹 → 缓存检查 → 评估并计算 \( s_{\text{adm}} \) → 满足阈值则准入经验。
  2. 云端聚合路径：对每个分组 \( u \)，检索经验组 \( G(u) \) 并更新 \( M_{\text{global}} \)。
  3. 边缘运行时路径：检查是否触发指导选择 → 如果有则从 \( M \) 中选取 \( \mathcal{G}_{\text{sel}} \) → 组装提示并执行。

## 6. 论文的主要结论与发现

- CoMIC 在不更新任何模型参数的前提下，显著提升弱边缘智能体的**进展率（PR）**和**动作基础准确率（GA）**，并带来任务依赖的成功率提升。
- 在场景 A 中，平均成功率从 0.00% 提升至 6.50%，PR 从 5.87 提升至 15.99，GA 从 32.53% 提升至 73.94%，同时上下文令牌消耗降低 27.88%。
- 在场景 B 中，强边缘智能体产生的高质量轨迹帮助云端提炼更有效的全局指导，弱边缘智能体的子目标级执行能力进一步提升（PR 提升至 17.77，GA 提升至 75.09），但成功率受限于弱基座模型的规划理解能力。
- 云端缓存命中率约 34%~45%，ACK 率约 40%~71%，说明云端指导有效传达了可采纳信息。
- 消融实验证实：去除云端后（仅 LOCAL）弱边缘无法完成任务（成功率 0~3%），加入云端后出现显著改善。

## 7. 优点：方法或实验设计上的亮点

1. **创新架构**：首次提出“集中反思、分散执行”的云-边缘协作范式，将计算密集的跨试验记忆维护与反思卸载到云端，边缘仅保留轻量级分层记忆，兼顾实时性与资源约束。
2. **无需参数更新**：完全基于提示工程和记忆优化，避免昂贵微调，易于在异构边缘节点部署。
3. **异步通信**：轨迹上传和指导下发均不阻塞边缘执行，保证低延迟。
4. **精细化经验过滤**：通过自报告置信度、重试惩罚、短轨迹惩罚计算准入分数，确保云端知识库质量。
5. **语义子目标标识**：支持跨边缘、跨任务的细粒度经验复用，提高指导的相关性。
6. **实验设计合理**：同时考虑了同构和异构边缘场景，并提供了全面的消融和云端开销分析，验证了各组件贡献。

## 8. 不足与局限

1. **边缘模型能力瓶颈**：CoMIC 的有效性依赖于弱边缘模型能生成**可行子目标**，并理解云端指导。极弱模型（如 <7B）可能无法顺利完成这两步。
2. **成功率提升有限且任务依赖**：部分任务（Gripper, Jericho）成功率仍为0%，最大提升仅 6.5% → 7.5%，远未达到与强模型（如 GPT-4）持平的水平。
3. **仅评估了 Mistral-7b**：未探索其他轻量级模型（如 Gemma-2B, Qwen-1.5B, Llama-3.2-3B）表现，泛化性不确定。
4. **云端评论者单一**：仅使用 deepseek-chat，未评估不同云端 LLM（如 GPT-4o, Claude 3.5）对结果的影响。
5. **实验重复性与统计性不足**：未报告多次运行的标准差或置信区间，难以判断结果稳定性。
6. **应用限制**：框架假定存在可靠云端连接，在网络不稳定或极致低带宽场景下可能失效。另外，云端处理延迟约 68~84 秒，不适用于亚秒级响应的实时任务。
7. **消融实验中的上下文开销**：在部分任务（Barman）中，CoMIC 上下文消耗反而比 LOCAL 增加18.6%，表明在子目标识别不准时引入云端指导可能引入冗余信息。
8. **未讨论隐私和安全**：边缘轨迹上传至云端可能涉及用户敏感数据，论文未涉及数据传输加密或隐私保护机制。
