## 摘要
最近的机制研究表明，在标准单轮任务中，大型语言模型（LLM）可能未能高效利用其深度。在自主智能体设置中（模型必须执行多轮规划、工具使用和迭代状态更新），这一情况是否仍然成立尚不清楚。我们通过对三个领域（深度研究、代码生成和表格处理）的完整用户-智能体轨迹进行系统的逐层分析来研究这一问题。利用残差流探针、因果跳层干预和有效深度测量，我们展示了智能体推理展现出与静态任务不同的深度特征。随着轨迹展开，模型逐步招募更多且更深的层，并在后续轮次中出现更强的远程层间依赖。同时，残差更新逐渐以修正为主导，表明从稳定的特征积累转向重复的重新校准。有效深度分析进一步揭示了一个显著的构建-精炼差距：语义方向通常较早形成，而深层对于稳定最终输出仍然是必要的。在不同模型家族中，这一差距在Qwen和Minimax中尤为明显，而GLM则表现出更依赖领域的深度分配模式。这些结果提供了机制证据，表明自主LLM智能体会随着推理复杂性的增长而自适应地分配深度。

## Abstract
Recent mechanistic studies suggest that large language models (LLMs) may utilize their depth inefficiently in standard single-turn tasks. Whether this still holds in autonomous agent settings, where models must perform multi-turn planning, tool use, and iterative state updates, remains unclear. We study this question through a systematic layer-wise analysis of complete user-agent trajectories spanning three domains: Deep Research, Code Generation, and Tabular Processing. Using residual stream probes, causal layer-skipping interventions, and effective-depth measurements, we show that agentic reasoning exhibits a distinct depth profile from static tasks. As trajectories unfold, models progressively recruit more and deeper layers, with stronger long-range inter-layer dependencies emerging in later turns. At the same time, residual updates become increasingly correction-dominant, indicating a shift from stable feature accumulation toward repeated recalibration. Effective-depth analysis further reveals a substantial construction-refinement gap: semantic direction often forms relatively early, while deep layers remain necessary for stabilizing final outputs. Across model families, this gap is pronounced in Qwen and Minimax, whereas GLM shows a more domain-dependent depth allocation pattern. These results provide mechanistic evidence that autonomous LLM agents allocate depth adaptively as reasoning complexity grows.

## 2. 方法论

### 2.1 核心思想
- 通过**因果层跳过干预**、**残差余弦相似度分析**和**有效深度测量**三种互补技术，对完整用户-智能体轨迹的每一层进行机制分析，追踪深度利用如何随交互轮次演化。

### 2.2 关键技术细节

#### (a) 因果层跳过干预（Future Effect）
- **目的**：量化某一层对后续层计算的因果必要性。
- **操作**：对位置 `p` 处的层 `s` 进行跳过干预（将该层输出替换为输入），然后测量下游层 `l` 的贡献向量（即残差更新）的相对变化。
- **公式**：
  \[
  E^{(r)}(s, l) = \max_p \frac{\|C_l^{(r)} - \tilde{C}_l^{(r)}\|_2}{\|C_l^{(r)}\|_2}
  \]
  其中 `C_l` 是原始贡献，`\tilde{C}_l` 是干预后的贡献。该值越大，表示层 `l` 对层 `s` 的依赖越强。

#### (b) 残差余弦相似度分析
- **目的**：判断每一层的更新是在**注入新特征**（正交）、**放大已有特征**（正对齐）还是**纠正/抑制特征**（负对齐）。
- **定义**：
  \[
  S_{\text{layer}}^{(r)}(l) = \cos\text{sim}(u_l^{(r)}, h_l^{(r)})
  \]
  其中 `u_l` 是注意力与 MoE 的总和贡献，`h_l` 是残差流输入。
- **解释**：正值为特征放大，负值为特征校正，近零为正交注入。

#### (c) 有效深度测量（Effective Depth）
- **余弦有效深度**：残差余弦相似度最后一次从负转正的位置，划分**构建阶段**（主动特征定向）与**精炼阶段**（特征放大）。
- **Logit Lens 有效深度**：基于中间层表示经语言模型头投影得到的输出分布，计算与最终分布的 KL 散度（下降至一半深度）和 Top-5 重叠（超过 0.3 阈值）时的层数。

### 2.3 算法流程（文字说明）
1. 收集完整多轮轨迹（包括 Thought、Action、Observation）。
2. 对每一轮，运行模型前向传播，记录所有层的残差流状态。
3. 执行层跳过干预：从选定的源层 `s` 开始，将其输出替换为输入（即跳过），然后计算下游各层贡献的扰动（Future Effect）。
4. 计算每层残差更新的余弦相似度。
5. 应用 Logit Lens 评估中层表示与最终输出的对齐程度。
6. 跨轮次对比上述指标，分析深度利用的演变。

## 6. 主要结论与发现

1. **渐进式层动员**：随交互轮次增加，模型逐步调用更多且更深的层，因果依赖从局部稀疏变为全深度密集；后期深层对预测至关重要，打破了静态任务中的浅层饱和模式。
2. **特征校正强化**：后期轮次中，残差更新出现更频繁的符号变化（正→负→正），表明模型从稳定的特征积累转向反复的**特征校正**，以维持状态一致性。
3. **构建-精炼分离**：语义方向（特征构建）较早形成（余弦有效深度约 40%），但深层仍被充分用于**稳定输出概率**（Logit Lens 有效深度接近 90-100%），存在显著“构建-精炼差距”。
4. **模型架构差异**：
   - **Qwen 和 Minimax** 遵循一致的构建-精炼分离模式，但 Minimax 的构建深度域间差异更大。
   - **GLM**（共享-稀疏专家混合）表现出强领域依赖性：代码/表格任务中构建深度大（74%），而深度研究中构建深度浅（28%），推测与稀疏专家的招募有关。
