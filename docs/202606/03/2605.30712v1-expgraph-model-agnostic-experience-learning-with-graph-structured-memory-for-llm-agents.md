## 摘要
大型语言模型（LLM）智能体在推理、工具使用和多步交互方面表现出强大的能力，但它们通常从零开始解决任务，未能重复利用先前经验中的成功策略或失败教训。对收集的经验进行微调可以改善重复利用，但当出现更强或更合适的执行器时，这种方法不够灵活。我们提出ExpGraph，一种模型无关的经验学习框架，使冻结且可替换的LLM执行器能够通过外部经验重用而无需参数更新来提升性能。ExpGraph将历史轨迹总结为可重用的技能和失败教训，将它们组织为自演化经验图中的节点，并通过图扩散和效用感知排序来检索有用的经验。利用强化学习训练一个轻量级的检索副驾驶，其反馈来自比较有无检索经验时的执行器性能，同时根据下游任务结果在线更新图。我们在ExpSuite上评估ExpGraph，涵盖问答、数学推理、代码生成以及多步智能体环境（包括ALFWorld和AppWorld）。在静态任务上，ExpGraph在较小和较大执行器上分别比最强基线提高12.2%和4.7%；在智能体环境中提高21.4%和12.7%，同时平均交互步骤减少12.7%和21.6%。消融实验表明，图结构经验、效用感知排序和自适应检索共同实现了跨不同任务和执行器模型的有效经验重用。

## Abstract
Large language model (LLM) agents have shown strong capabilities in reasoning, tool use, and multi-step interaction, but they often solve tasks from scratch and fail to reuse successful strategies or failure lessons from prior experience. Fine-tuning on collected experience can improve reuse, but it is inflexible when stronger or more suitable executors emerge. We propose ExpGraph, a model-agnostic experience learning framework that enables frozen and replaceable LLM executors to improve through external experience reuse without parameter updates. ExpGraph summarizes historical trajectories into reusable skills and failure lessons, organizes them as nodes in a self-evolving experience graph, and retrieves useful experiences through graph diffusion and utility-aware ranking. A lightweight retrieval copilot is trained with reinforcement learning using feedback that compares executor performance with and without retrieved experiences, while the graph is updated online from downstream task outcomes. We evaluate ExpGraph on ExpSuite, covering question answering, mathematical reasoning, code generation, and multi-step agentic environments including ALFWorld and AppWorld. ExpGraph improves over the strongest baseline by 12.2% and 4.7% on static tasks with smaller and larger executors, and by 21.4% and 12.7% in agentic environments, while reducing average interaction steps by 12.7% and 21.6%. Ablations show that graph-structured experience, utility-aware ranking, and adaptive retrieval jointly enable effective experience reuse across diverse tasks and executor models.

### 核心思想
ExpGraph 将历史轨迹总结为可复用的技能（成功轨迹）和失败教训（失败轨迹），组织成自进化的经验图；对于新任务，通过语义种子选取、图扩散、效用感知排序检索最有用的经验，输入冻结执行器的上下文；并利用强化学习训练一个轻量级检索副驾驶来自适应控制检索策略。执行器永不更新，仅经验图和检索副驾驶演化。

### 关键技术细节
1. **轨迹-经验转换**：每条轨迹 τ=(x, ξ, y, s) 被压缩为自然语言经验单元 e = Summarize(τ)。高得分轨迹提炼为技能，低得分轨迹提炼为教训。每个经验成为图节点 v = (e_v, h_v, u_v, n_v)，包含文本、嵌入、效用估计、检索计数。
2. **图构建**：新节点插入时，连接其 top-K 余弦相似邻居（相似度≥阈值 θ），保持图稀疏性。
3. **检索副驾驶**：轻量级模型 π_ret 为任务输出两个离散控制变量 (R, W) ∈ {0,…,100}²，对应扩散广度 ρ = R/100 和语义-效用权衡 λ = W/100。
4. **检索流程**：
   - 语义种子选取：任务嵌入与节点嵌入余弦相似度取 top-m 节点为种子集 S0。
   - 图扩散：以 S0 为重启分布执行个性化 PageRank，扩散深度受 ρ 控制（ρ 越大越接近种子）。
   - 效用感知排序：对扩散后候选节点计算 UCB 得分 b_v = u_v + c √(log(N+1)/max(n_v,1))，最终得分 score(v|x) = (1-λ)·d_sim(x,v) + λ·b_b_v，取 top-K 作为检索结果 E。
5. **效用导向奖励**：在有无检索经验两种条件下执行任务，得到 s_with 和 s_without，奖励 r = (s_with - s_without) + η·s_with，第一项衡量检索边际增益，第二项鼓励绝对任务质量。
6. **优化**：检索副驾驶通过 PPO 最大化期望奖励；执行器 π_exec 永不更新。
7. **在线图演化**：任务完成后，更新被检索节点的计数和效用（指数移动平均），新轨迹被总结为新节点插入图，容量超标则淘汰低效用低频次节点。

### 算法流程文字说明
- 循环：采样任务 → 副驾驶预测 (R, W) → 语义种子 + 图扩散 + 效用排序 → 检索得到 E → 用 E 执行获得 s_with → 不用 E 执行获得 s_without → 计算奖励 r → PPO更新副驾驶 → 更新图节点效用 → 新轨迹总结为节点并插入图 → 继续下一循环。

## 3. 实验设计

### 数据集/场景
论文构建了 **ExpSuite**，包含：
- **ExpSuite-Static**：单轮静态任务（10个基准）
  - 问答（QA）：ARC-C、CommonsenseQA、GPQA、MMLU、OBQA（报告准确率）
  - 数学推理：GSM8K、GSM-Symbolic、MATH（报告精确匹配）
  - 代码生成：HumanEval+、MBPP+（报告 Pass@1）
- **ExpSuite-Agentic**：多步交互智能体环境
  - ALFWorld（Seen/Unseen 两拆分）：报告成功率(SR)和平均步骤
  - AppWorld（Test-Normal/Test-Challenge 两拆分）：报告通过率(PR)和平均步骤

### 执行器模型
- 静态任务：小型 Llama-3.2-3B-Instruct、大型 Llama-3.1-8B-Instruct（均冻结，通过API调用）
- 智能体任务：小型 Qwen3-32B、大型 Gemini-3.1-Flash-Lite（均冻结，通过API调用）

### 对比方法
- **No Memory**：直接使用冻结执行器，无外部经验
- **检索类经验学习基线**：ReasoningBank、ExpeL、LightMem、Mem0、AWM、MemRL
- **LLM类经验学习基线**：IRCoT、Search-o1、S3
- **提示式智能体基线**（仅Agentic）：ReAct、Reflexion
- 所有基于经验的方法均给予与ExpGraph相同数量的经验，确保差异来源于经验利用方式而非数据量。

## 6. 论文的主要结论与发现

1. **最佳总体性能**：ExpGraph 在所有评估设置和执行器上取得最佳平均性能。
   - 静态任务：较小执行器提高12.2%，较大执行器提高4.7%。
   - 智能体环境：加权平均得分分别提高21.4%和12.7%，同时交互步数减少12.7%和21.6%。
2. **更受益于经验复用的场景**：较小执行器比大执行器获益更多；智能体环境比静态任务增益更大。表明经验复用在执行器内化能力较弱或任务需要长程决策时更有价值。
3. **有效的执行器间迁移**：
   - 小→大迁移：经验组件从小执行器迁移到大执行器性能损失最小，图+副驾驶联合迁移最接近目标专用ExpGraph。
   - 大→小迁移：更具挑战性，但仍有效，弱执行器仍可从高质量经验中获益。
   - 非推理→推理迁移：强执行器能更好解释和适配迁移的经验，表现优异。
4. **消融验证各组件必要性**：移除图扩散、效用排名、相似度过滤或用扁平池替代图结构均导致性能下降，其中扁平记忆下降最大，说明图结构连接相关经验至关重要。

## 7. 优点

- **模型无关性创新**：完全将经验学习与执行器训练解耦，执行器可替换、可冻结（闭源/昂贵/不可修改均可），极大提升灵活性和部署友好度。
- **图结构记忆设计**：超越扁平最近邻检索，通过图扩散发现语义或策略上相关的经验，引入关系信息。
- **效用感知检索**：结合语义相似度和历史效用（含UCB探索），不仅匹配表面相关，更选择真正能提升下游性能的经验。
- **自适应控制**：检索副驾驶预测(R,W)两个连续参数，根据任务和执行器自适应调整扩散广度和效用权重，可针对不同任务类型学习不同策略。
- **奖励设计合理**：区分边际增益（with - without）和绝对任务质量（η·s_with），引导副驾驶追求真实改进而非仅超越弱基线。
- **实验全面**：多种任务、两种执行器规模、零样本迁移、详细消融、案例研究，提供充分证据。
- **效率提升**：不仅提高成功率，还显著减少交互步数，体现决策效率优势。
- **开源**：承诺公开代码。

## 8. 不足与局限

- **实验覆盖有限**：任务聚焦于问答、数学、代码及ALFWorld/AppWorld，未涵盖更长程的真实世界应用（如网页浏览、科学发现、多智能体协作）。作者在论文附录A中承认这一点。
- **图构建固定超参数**：邻居数、相似度阈值、容量、效用更新率等均为固定值，可能在不同领域或经验分布下不够鲁棒。作者指出可探索自适应图构建和剪枝策略。
- **反馈信号粗糙**：仅使用任务最终得分的标量奖励，未利用中间步骤或过程级信用分配（如过程奖励模型），可能削弱学习信号。
- **提示式依赖**：经验通过提示注入执行器上下文，但提示级指令向模型行为的转化不一致（引用相关文献），更紧密的耦合（如微调或蒸馏）可能更有效。
- **计算开销**：每次任务需执行两次执行器（有/无检索），在成本敏感场景可能受限。但相比微调，这种方法仍然更灵活（不修改执行器参数）。
- **基线调优偏差**：基线方法可能未像ExpGraph那样经过充分RL优化，尽管相同的经验数量确保了一部分公平性，但方法本身的优化差异仍可能存在。论文未报告对基线进行超参数搜索的细节。
- **迁移实验局限性**：零样本迁移中，副驾驶可能不完全适配目标执行器，尽管图+副驾驶联合迁移表现最好，但仍有损失。作者指出小→大迁移比大→小迁移更容易。
- **可扩展性未充分讨论**：当经验图增长到数万节点时，图扩散和在线更新的计算效率需进一步评估。论文设定容量2000节点，真实场景可能需要更大。
